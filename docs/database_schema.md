# CloudFlow AI Support Assistant Database Schema

This document details the database schema stored in the local SQLite engine (`cloudflow.db`).

## Entities

```mermaid
erDiagram
    CONVERSATIONS ||--o{ MESSAGES : "contains"
    CONVERSATIONS ||--o{ TICKETS : "escalates"

    CONVERSATIONS {
        int id PK
        string session_id UK
        string summary
        datetime created_at
        datetime updated_at
    }

    MESSAGES {
        int id PK
        int conversation_id FK
        string role
        text content
        string intent
        string sentiment
        float confidence
        json citations
        datetime created_at
    }

    TICKETS {
        int id PK
        int conversation_id FK
        string subject
        text description
        string status
        string priority
        string category
        datetime created_at
        datetime updated_at
    }

    DOCUMENTS {
        int id PK
        string title
        text content
        string category
        string source_url
        datetime created_at
        datetime updated_at
    }
```

### Table Details

1. `conversations`: Stores conversational session logs.
2. `messages`: Single message objects (user, system, or AI responses). Handles metadata generated by NLP pipelines (sentiment, intents, and RAG search citation snippets).
3. `tickets`: Tracks escalated tickets if the scorer outputs low confidence.
4. `documents`: Tracks raw ingested help articles.
